# 계산 수정 내역 (2.305 구조 + 2.323 툴팁 수치)

## 원칙

- 복호화된 맵은 2.305뿐이다. 2.323 수치는 ORDR.kr 툴팁(`dist/ordr_units.json`, 2026-10-14 수집)에서 가져온다.
- **구조는 2.305 맵, 수치는 2.323 툴팁**. 구조란 발동 방식·대상·범위/단일·피해 타입·자원 규칙·변신 방식, 수치란 계수·고정 피해·확률·쿨·체력 비율이다.
- 툴팁에 수치가 없으면 2.305 값을 `[2.305 기준]`으로 쓴다. 둘 다 없으면 `[추정]`.
- 근거 표기: `[툴팁 코드]` = `dist/ordr_units.json`의 해당 유닛 문장, `[2.305 j:줄]` = `war3map.j`, `[2.305 wts:줄]` = `war3map.wts` (`dist/resources/maps/s2-2305-extracted.zip` 압축 해제 기준 줄 번호).
- 결과 비교: `node scripts/hero_results.mjs docs/results/<단계>.json`. 기본 옵션(방깎 201, 범위 적중 100%, 레드포스호·자원 만충·소환 포함), 각 유닛 1기·3기의 60~65라 라운드별 잔존 수. 수정 전 기준은 `docs/results/00_baseline.json`(main `aa6ff9d`).
