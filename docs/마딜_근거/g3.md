## new_semantics
1. `speed_scaling` (TR14): 이벤트 피해에 1 + k×(대상 현재 이속 + 16.25)를 곱하는 필드다. 위치 모델은 실제 이속을 쓰고, 기본 모델은 난이도의 무감속 이속을 쓴다.
2. `on_approach.stun` (TR13): 접근 스킬이 접근한 적에게 스턴을 거는 필드다.
3. on_approach 공유 키 (TR13·Z8): 2.305에서는 두 영웅이 TurnSpeed 0.49 표시를 공유해 한 적에게 하나만 발동한다.
