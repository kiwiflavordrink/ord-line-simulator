  - `j:N`: 2.305 `war3map.j`의 줄
  - w3u·w3a·w3q: 2.305 오브젝트(`w3o_D.py`로 파싱)

## 공통 규칙 (이 그룹에서 정한 것)

1. **스탯**: ORDR에 스탯 블록이 없으므로 모두 `[2.305 기준]`이다.
   - 공격력 = ua1b + 주사위 평균 + gba2 + 20×gmo2
   - 공속 = (1 + min(gba1 + 20×gmo1 + 유닛 AIsx, 4)) / ua1c
   - 다섯 영웅 모두 업그레이드는 **R004 제한 업그레이드**(gba1 1.85, gmo1 0.05, gba2 20000, gmo2 2000, glvl 21)를 쓴다. Z9 h05F 92,501.5로 식을 검산했다.
   - ua1s가 없는 유닛(h040, h05E)은 Z2 관례에 따라 주사위 평균을 0으로 두었다. 차이는 몇 포인트다.
2. **2.323 카드에 아예 없는 2.305 능력은 넣지 않았다.** 대상은 크리티컬, 마나 오라, 추가 타격처럼 카드 문장이 없는 효과다. 이런 효과는 `unmodeled`에 "[2.305에만 있음]"과 영향 크기를 적어 두었다.
   - 근거: ORDR은 같은 등급 다른 유닛의 크리(TR9·E6), 자기 공속(TR2), 마나재생(◎ 마나재생 N)을 카드에 적는다. 그래서 빠졌다면 2.323에서 바뀌었을 가능성이 있다고 보았다.
   - 에넬은 역할 태그에도 '단일스턴'이 없다. 2.305 A0E6의 50% 타격 스턴이 사라졌다는 정황이다.
   - 예외: 카드에 있는 스킬 안의 빠진 수치는 2.305 값을 `[2.305 기준]`으로 썼다. 예는 마르코 봉황인의 특수몹 20만, 스턴의 영웅 지속 비율, 분신 수명 2.25초다.
3. **특강**은 모두 무특강(base_lines)으로 계산했다. 특강 차이는 `unmodeled`에 적었다.
4. **피해 타입**은 툴팁 문구를 따랐다. 2.305 코드와는 아래와 같이 대응한다.
   - NORMAL·UNIVERSAL은 마법이다.
   - CHAOS·UNIVERSAL은 고정이다.
   - CHAOS·NORMAL은 툴팁에 '물리'로 나온다(레드필드 타격, 마르코 불사조).
   - HP 비례 MELEE/PIERCE·UNIVERSAL에 ×(0.79+0.01×A11S)를 곱하는 것은 폭발형이다.
5. **"보스" 분기**: 2.305 코드의 보스 판정은 대부분 A902(보스)·A911(미션)·A904(스토리)이고 A903(광폭)은 빠진다. 그래서 광폭은 라인 쪽 수치를 받는다. 이것을 `boss_parts`/`target: boss`로 표현했다. 에넬 낙뢰와 마르코 봉황인은 A903을 포함하므로 `target_special`/`special`로 표현했다.
