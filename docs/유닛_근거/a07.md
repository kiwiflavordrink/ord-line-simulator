- 비교: 같은 조건의 E7 에이스 영원은 1기 61라 패배, 3기 클리어다. TR3·E6는 1기 64라 패배 또는 클리어로, 상위 등급이 더 강하다. 변화·왜곡·세라핌 1기가 61라에서 지는 것은 등급과 맞다.
- D1 3기 클리어 원인:
  - 잃은 체력 비례 물리 피해가 복리로 커진다. 해당 피해는 평타 0.75%와 타오르란 5%(900범위)다.
  - 기본 모델은 범위 적중을 100%로 둬서 이 효과가 과장된다.
  - 위치 모델에서는 61라에서 패배한다.
  - 수치는 툴팁 그대로다. 실제 게임에서도 잃은 체력 비례 피해는 누적되지만, 3기 클리어는 기본 모델(coverage 1)의 상한으로 읽어야 한다.
