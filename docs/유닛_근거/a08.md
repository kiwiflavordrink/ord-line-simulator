# a08 신비함 MY1~MY13 근거와 검증

공통: 구조는 2.305 맵(war3map.j·w3u·w3a·w3q), 수치는 2.323 ORDR 툴팁(dist/ordr_units.json base_lines/trait_lines/buff_lines). 13기 모두 2.305 w3u에 '이름 - 신비'로 있고(h09M 고죠, h0BF 네즈코, h0A2 시키, h09W 미나토, h08I 뱌쿠야, h09N 부릉냐, h083 샌즈, h08M 아냐, h0A6 유카리, h0CC/h0CD 요우무·반령, h09R 죠타로, h0BC 타츠마키, h0AC 히그마), 엔진 하드코딩 유닛이 아니라 전부 등록했다.

**풀업 공식(신비 공통)**: w3u upgr 첫 항목(R01P·R01R·R01L)은 Rhse 조건용 업그레이드라 수치가 없어, 수치가 있는 R019 '랜덤전용 유닛 업그레이드'(Rugf)를 썼다. R019는 gba1을 저장하지 않아 Rugf 기본값 0.25(w3q gub1 '기본 공격속도 증가량 : 25%'), gmo1 0.14, gba2 1000, gmo2 1000, glvl 21. 여기에 모든 신비 유닛의 A13I(AIsx 0.25, gub1 '신비 유닛은 최종 공격속도가 25% 더 높습니다')를 공속 보너스에 더했다: 공격력 = ua1b + 주사위 평균 + 21000, 공속 = (1 + min(3.30 + 자체, 4)) / ua1c. 샌즈만 R00Q(뼈 개수 = 레벨). ORDR 2.323에는 신비 유닛 스탯 블록이 없어 평타 수치는 [2.305 기준].

**자원 규칙**: 2.305 각 공격 트리거에서 '자원 == 최대이면 0(또는 체력 1)으로 하고 스킬, 아니면 +1' 구조를 확인했다(유닛별 줄 번호는 이벤트 note). 시전 공격은 +1이 없으므로 주기 = 비용/(공속×공격당 + 재생) + 1/공속. 경직(BlzPauseUnitEx)이 있는 스킬은 attack_uptime과 확률 rate에 가동률을 곱했다.
