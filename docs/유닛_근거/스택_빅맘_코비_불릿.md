# 스택 시나리오 2 — I6 빅맘 영혼 · TR24 코비 버프 수 · I5 불릿 아이템 중첩

`stacks2.json`의 변형은 `dist/data.json`의 `hero.stack.variants`와 같은 형식이다. `build_stacks2.py`로 만들고 `validate2.mjs`로 검증했다. 결과는 `validation2.json`에 있다. 저장소는 수정하지 않았다.

- I6: `slot: stack`이다. 데이터 값 s=1은 zero와 같다.
- TR24: `slot: extra_stacks`다. 이 영웅의 주 스택은 이미 군함 백이다. 버프 수 변형은 군함 백 6레벨 데이터 위에 적용한다.
- I5: 데이터에는 아이템 효과도, 마나 스킬 이벤트도 없다. 그래서 `hero_patch`/`patched_hero`(max 상태)를 제안한다. 변형은 패치된 영웅을 기준으로 만들었고, max 변형은 `{}`다.
- 검증 조건: `simulateV2`, 신 난이도, 기본 옵션과 `positionModel`, 1기와 3기. 예외와 NaN은 0건이다. 엔진 `stackVariant`(`options.stackLevels`)로 교차 확인한 결과도 I6·I5에서 직접 적용한 결과와 같았다.

## 1. I6 빅맘 — '영혼' 스택

### 플레이어용 설명

- **영혼이란**: 빅맘(불멸)을 조합하면 '포식한 영혼'(I00B) 아이템을 받는다. 이 아이템의 충전 수가 영혼 스택이다. 시작 값은 1이다. 아이템은 플레이어마다 하나다. 빅맘(불멸)은 1인 1기만 조합할 수 있다.
- **얻는 법**: 영혼포식은 공격 시 12.5% 확률로 발동하고 절대쿨다운이 6.25초다. 라인 몬스터를 공격하다 발동하면 900 범위의 랜덤 라인몹을 즉사시킨다. 이 즉사 1회마다 18.5% 확률로 영혼이 +1된다. 보스·광폭을 대상으로 한 특수 발동(450만 고정)은 영혼을 주지 않는다. 즉사 대상으로 특수몹이 뽑힌 경우도 마찬가지다.
- **효과**: 영혼 1개당 영혼포식 피해가 1% 증가한다. 대상은 비라인 450만 고정 피해와 600 범위 175만 마법 피해다. 특강(A0RZ 2레벨)이면 확률이 50%, 증가량이 2%/스택이 되고 프로메테우스·불꽃 칼에도 배율이 붙는다. 특강 효과는 데이터 범위 밖이다.
- **상한·단계**: 2.305 코드에 상한도 단계 구분도 없다. 계속 쌓인다.
- **라운드 간 유지**: 아이템 충전이라 게임이 끝날 때까지 유지된다. 초기화 코드가 없다.

### 추정

가정은 다음과 같다.

- 60라 이전: 교전 시간은 라운드당 약 19초다(35기를 0.5초 간격으로 생성 + 이동). 평균 공속은 1.6, 즉사 주기는 0.96 + 6.25 + 1/(0.125×공속)초다. 그래서 라운드당 시전 1.56회, 영혼 0.29개다.
- 60~65라: 라인몹이 계속 남아 있어 데이터 rate 0.0918/s를 쓴다. 라운드(32초)당 시전 2.94회, 영혼 0.54개다.

|---|---|---|
| 20라 | 12.5 | 15.8 |

| 40라 | 6.8 | 10.0 |

- 변형 값: zero = 1(코드 최소 = 시작 값), half = 7, max = 13. max는 30라에 조합했을 때 65라 종료 시점의 기대값이며, 코드 상한이 아니라 추정이다.
- 바뀌는 이벤트: 영혼포식 특수 `parts`, 영혼포식 즉사 `nonline_parts`, 영혼포식 범위 `parts`. 모두 (1 + 0.01s) 배율이다.

## 2. TR24 코비 — 버프 수

**세는 방식(코드)**: `UnitCountBuffsExBJ(bj_BUFF_POLARITY_EITHER, bj_BUFF_RESIST_EITHER, 코비, true, true)`로 센다(kPA j:65150; 어니스티 gie j:60840; 육식 qPe j:74933). 양성·음성, 마법·물리, 시한 버프, 오라 버프를 모두 센다. 따라서 코비에게 붙은 서로 다른 버프 id의 개수다. 아군 버프와 아군 대상 디버프 오라를 모두 포함하고, 같은 id는 소스가 여러 개여도 1개로 센다.

**적용식**: 버프 수를 b라 하면 다음과 같다.

- 어니스티 임팩트: 355만 × (1 + 0.023b)
- 육식: 20만 × (1 + 0.23b)
- 영웅의 후계자: 1만 × b 고정
- 분신 소환 확률: (500 + 23b)/10000. 분신 이벤트 3개의 rate가 0.05 + 0.0023b에 비례한다.
- 데이터 값은 b = 3이다.

## 3. I5 불릿 — 유니언 아르마다 아이템 중첩

### 아이템과 획득 한도 (2.305)

- **세는 아이템**: I091 유니언 아르마다 :: 공격력, I092 :: 공격속도, I093 :: 방어력 감소, 3종이다.
- **지급**: 불릿(불멸)을 조합할 때 각 1개만 지급된다(oSM j:72869-72872). 불릿은 1인 1기다(j:72843). 상점 판매·드롭·조합 경로가 없다(igol 0).
- **충전 방법**: 아이템을 자기 '흔함' 유닛에 사용한다. 그 유닛은 제거된다(AmM j:6637-6655). 사용할 때마다 40% 확률로 +1, 60% 확률로 +2다(QoM j:40812-40822, yoA j:85022-85031, OdA j:37315-37324).
- **상한**: 아이템마다 최대 30이다(SetItemCharges 30). 30에 도달하면 Lv.Max 아이템(I006~I008, 사용 능력 없음)으로 교체되어 더 쌓이지 않는다.
- **단계**: 시작 1 → 15 유니크(레벨 2) → 30 레전더리(레벨 3).
- **필요 흔함 유닛 수(평균)**: 1에서 15까지 아이템당 8.8기, 30까지 18.1기, 세 아이템 모두 30까지 약 54기다. 맵 차원의 상한은 없고 흔함 유닛(자원) 수가 한계다.
- **변형 값**: zero = 1, half = 15, max = 30(코드 상한, 세 아이템 모두 같은 값).

n의 해석이 두 가지라 변형도 두 벌로 만들었다.

- 주 변형 `variants`: n = 아이템 충전 수다. 2.323 툴팁과 2.305 툴팁의 문구 "아이템 중첩수"를 따른다.
- 대안 `variants_code_n`: n = 단계 레벨(1~3)이다. 2.305 코드는 피해식에 능력 레벨을 넣는다(A0WO j:11762, A0WQ·A0WO j:44362-44363, A0WQ j:83408).

2.305 코드의 패왕색은 툴팁과 크게 다르다. 1단계에서는 피해가 없고, 2단계에서는 (25만 + 현재 2%) × n%만 들어가며, 보스 피해는 3단계에서만 생긴다. 2.323 툴팁의 단계와 식을 쓰고 [추정]으로 표시했다.

`attack_uptime`(0.955 / 0.953 / 0.951)과 매 공격 이벤트의 rate에 스트라이크 경직을 반영했다. 육식-체의 버프 비율 '공격당 0.21'은 데이터 값을 유지했다. 기하분포로 계산하면 약 0.43이라 데이터가 과소평가일 가능성이 있다.
