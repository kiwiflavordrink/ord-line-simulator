# a16 — 카탈로그 밖 플레이어 유닛·특수 기물 (2.305 맵 조사)

대상: 2.305 맵에서 플레이어가 쓸 수 있고 60~65라 라인몹 전투에 기여할 수 있으나 ORDR 2.323 카탈로그(271종)에 없는 유닛·기물.
방법: w3u 1,398종 전체를 이름·등급 접미사로 카탈로그와 등급별 대조(`a16w/match.py`, 등급별 개수 비교), 남은 후보마다 war3map.j 생성 지점(16진 rawcode `$68303630` 형태)과 등록 트리거(owe/aGM)로 소유·획득 경로를 추적했다. 2.323 수치 근거는 ORDR 패치노트(2-305~2-323, 9쪽만 내려받음)뿐이며 도움소 관련 언급은 2.310 '출항 50%→40%' 하나다.

결과 파일: `a16.json` — heroes 4개(OB1 도움소, OB2 군함, OB3 해적선, XR1 레일리 희귀), `item_effects_2305`, `skipped`, `catalog_related`, `new_semantics`.

- half M=5000: 흡수 49, 버스터콜 1, 낙뢰 1.
- zero M=0: 재생분만 쓴다(흡수 0.3/90 /초).

## 4. OB3 해적선 / XR1 레일리(희귀)

- 해적선 h060: ua1b 510 + 주사위 2 [추정] + R00F +21 + R00E +440 = 973. 공속 (1+0.28)/0.9 = 1.42이며, R00E gba1이 미설정이라 0으로 가정했다. normal 타입, 사거리 600, 비행. 조합 재료 유닛이고 DPS는 약 1.4천이라 실질 기여가 없다.
- 레일리 희귀 h05X: 20000 + 2 + 200 + 15×200 = 23,202, 공속 2.3/0.85 = 2.706, pierce, 사거리 600. 명왕의 검술 A0F8(AHbh)은 추가 피해 60000, 스턴 0.5/0.25초다. 확률 필드가 미설정이라 AHbh 기본 20%를 썼다(1.27 abilitydata). ORDR 카탈로그 희귀 42종은 2.305 희귀 45종에서 레일리·고대의 배·장난감을 뺀 것과 정확히 맞으므로, 2.323에서는 빠졌거나 숨겨진 유닛일 가능성이 있다.

- 군함은 150초마다 700만 범위 고정 피해라 보조 수준이다.
- 해적선·레일리 희귀는 60~65라에서 의미가 없다. 저등급이라 정상이다.

## 7. 한계·new_semantics

- `execute_line`은 공격 대상만 처형한다. 흡수는 사거리 99999로 아무 라인몹이나 처형할 수 있는데, 보스가 있는 60·65라 기본 모델에서는 처형이 0으로 나와 과소 평가된다(OB1 단독 기본 모델 처형 0).
- rate는 192초 평균이다. 실제로는 시작 시점에 몰아 쓰므로 초반 기여가 과소 평가된다.
- 2.305 수치만 있다. 2.323 도움소 스킬 존재·수치는 2.310 출항 외에는 미확인이다.
- 기록지침 보물(아군 공속 +10/+4%, 공격력 +14/+7%/+5000, 적 방어 −6/−3, 이감 7%, 마방깎 5, 폭발형 +5%)은 유닛이 아니어서 넣지 않았다. P1 시작 위치 (−3776,4480)에서 라인 루프 전 구간까지 최대 약 1675이므로 1850 오라는 라인 전체에 들어간다. 옵션화를 제안한다.
