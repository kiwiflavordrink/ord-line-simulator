## 공통

- 유닛 매칭: ORDR 이름 → 2.305 w3u `"이름 - 희귀"`. R37 "캡틴 키드" = h02D "유스타스 키드 - 희귀"(희귀 키드는 이것 하나), R41 "페로나 홀로홀로" = h05K "페로나 - 희귀", R33 = h02F "조로 현상금사냥꾼", R34 = h02E "다이아몬드 죠즈", R31 = h02A "엠포리오 이완코브", R42 = h01M "보아 핸콕".
- 풀업: 14종 모두 upgr R008 "희귀 업그레이드"(Rugf, gba2 200, gmo2 200, gba1 0.7, gmo1 0.04). **R008 glvl = 16**(최대 단계)이라 21이 아니라 16단계를 썼다. 공격력 = ua1b + 2(hrif 기본 1d3, TR25 관례) + 3200, 공속 보너스 +1.3. AIsx(아이템 공속) 능력이 있으면 더했다(R35 −0.5, R36 +0.33).
- 공격 타입: ua1t, 미설정(R33·R39)은 hrif 기본 관통. 무기 모두 missile/기본 → 스플래시 없음. rounds는 같은 타입 기존 영웅 값.
- 트리거: 각 유닛의 공격 트리거는 `aGM(<유닛 id>, <code>)` (war3map.j:90775–90792) → `set X=function …` (j:86523–86537). h02D(키드)·h05K(페로나)는 aGM 없음(능력만).
- 데미지 함수: `AyM(src,tgt,dmg,min,max,…)`, `oCM(src,0,r,loc,dmg,min,max,…)`는 dmg×random(min..max) (j:5318–5325) → 기대값 (min+max)/2. NORMAL·UNIVERSAL = 마법, SIEGE·NORMAL = 물리, MELEE·UNIVERSAL = 폭발형(기존 관례).
- 2.323 툴팁(has_tooltip true)은 R31·R35·R37·R38·R41·R42뿐이고, R35·R37·R41은 버프 줄만 있다. 나머지 수치는 모두 `[2.305 기준]`.
- 특강(trait_lines) 있는 유닛 없음. 스택 없음.
