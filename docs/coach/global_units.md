# 맵 전체·팀 효과 유닛 조사 (코치용)

조사일 2026-10-24. 근거: 2.323 툴팁 `dist/ordr_units.json`, 2.305 맵(`scratchpad/map2305/war3map.w3a·w3u·j·wts`), ORDR.kr 가이드. 기계 판독용: `global_units.json`(같은 폴더), 2.305 영웅 오라 반경 전체 목록: `aura_ranges_2305.json`.

## 0. 판정 규칙 (WC3 구조)

- 오라 범위 `aare 99999` + 대상 `enemies` → **맵 전체 모든 적**(모든 플레이어 라인몹·보스·스토리).
- `aare 99999` + `friend` → **맵 전체 모든 아군 플레이어 유닛**. `player` → **자기 유닛만**.
- 같은 버프 ID 오라는 몇 개가 있어도 **1번만** 적용되고(가장 센 값), 버프 ID가 다르면 합산된다(`scratchpad/wc3_rules.md` §2, 커뮤니티 근거).
- 플레이어 영역 4곳(`ch[0..3]`, 3232×3296)은 서로 2784 이상 떨어져 있다(j:71333-71336, j:90534-90555). 그래서 일반 오라(600~1250)는 **다른 플레이어 라인에 닿지 않는다**.

### 스토리 존 배치 (팀 판단에서 가장 중요)

- 스토리는 Player(5)가 가진 **공유 유닛 1개**이고 위치는 `Ht` 중심 (-6768,-5072)이다(j:90584, j:10807). 화면에 "실시간 스토리 기여도"를 플레이어별로 보여 준다.
- 스토리 존에 들어간 유닛은 플레이어별 자리 `Xh[pid]`로 순간이동한다. 보스·미션유닛이 살아 있으면 이동이 거부된다(j:21786-21797, j:90575-90578).
  - 자리: P1 (-7088,-4784), P2 (-6480,-4784), P3 (-7088,-5360), P4 (-6480,-5360).
  - 자리 → 스토리 거리 약 **430**.
  - 자리 ↔ 자리 거리: 가로 **608**, 세로 **576**, 대각선 **838**.
- 이 배치에서 생기는 결과:
  - **스토리에서는 모든 플레이어의 적 대상 방깎·이감 오라가 스토리에 닿는다.** 2.305 적 대상 디버프 오라 100개 중 가장 짧은 것이 600이고 대부분 800~925다.
  - 같은 버프가 겹치면 1번만 적용되고, 다른 버프는 합산된다.
  - 아군 버프 오라는 범위 850 이상이면 다른 3명 모두에게 닿는다. 800~825는 상하좌우 이웃만 받는다. 경계값은 근사다.
- 파티 플레이에서는 "스토리의 체력 및 방어력이 플레이어 수 만큼 증가"한다(j:37901). 배율은 확인하지 못했다.

### 우타 영원 판정 (사용자 진술: "맵 전체")

- 2.305 맵에서는 맵 전체가 아니다. 우타월드 오라 A0KN(공격력 30%)과 A0KO(이감 45%)는 **1250 범위**이고, 우타 위치에 생기는 더미 e0RE에 달려 우타를 따라다닌다.
  - 2.305의 '$원피스' 보상 능력 A0KR·A0KT(aare 99999)는 우타 툴팁 문구를 복사해 쓴 것이다. 실제로는 보물지도를 모두 찾은 플레이어 **본인**에게 주는 보상이다(atar player, j:84068-84071).
- 2.323 툴팁에는 범위 수치가 없다.
- 그런데도 사용자가 "모두에게 적용된다"고 느끼는 이유는 스토리 존 배치로 설명된다. 1250 범위가 자리 사이 최대 거리 838과 스토리까지 430을 모두 덮는다. 그래서 스토리에서는 우타 1기가 4명 전원의 공격력 +30%, 공속 +15%와 스토리 이감 45%를 담당한다.
- 각 라인에서는 자기 라인에만 적용된다.
- **코치 처리:**
  - 스토리 판단: 우타를 팀 버프로 1번 셈.
  - 라인 판단: 소유자에게만 셈.
  - "2.323에서 맵 전체로 바뀌었다"는 근거는 없으므로 `미확인`으로 표시한다.

### 우솝 초월 판정

- 우솝 초월은 맵 전체 방깎 **8**이 확정이다. 모든 플레이어의 라인몹·보스와 스토리에 적용된다.
- 같은 우솝이 여러 기 있어도 8은 1번만 적용된다.
- 로컬 22(1085범위)는 자기 라인과 스토리에만 적용된다.
- 시뮬레이터(data.json `own_armor_cut` 22)와 ORDR 계산기(buff_lines 합산)는 **맵 전체 8을 세지 않는다**. 팀 코치는 다음처럼 따로 더해야 한다.
  - 다른 플레이어 라인: +8
  - 우솝 주인 라인과 스토리: 22+8

### 범위를 확인해 제외한 것

- 2.305 w3a에서 범위 ≥ 5000인 영웅 오라는 A0OS·A0Q7·A0LZ·A07Z 4개뿐이다.
- 나머지 대범위 능력은 다음과 같아 제외했다.
  - 배틀로어 더미(atar player)
  - 투사체
  - '@' 아이템과 '$' 연구·보물 보상: aare 99999이지만 atar player라 본인만 받는다.

## 2. 가이드 요약 (ORDR.kr, 2026-10-05 갱신, 데이터 2.323)

> 주의: 가이드의 목표 수치는 **한 플레이어 조합의 오라 합산**(유닛 설명 첫 줄 buff_lines) 기준이다.
> - 팀 합산, 맵 전체 효과, 스토리 공유는 다루지 않는다.
> - 발동형은 계산기에 포함되지 않는다.

### 방깎·이감 목표 (https://ordr.kr/guides/armor-reduction, /guides/slow, /guides/hell, /guides/god, /guides/nightmare)

| 난이도 | 방어력 감소 목표 | 이동속도 감소 목표 | 워큐리 적용 시 방깎 | 나스쥬로 적용 시 이감 |
|---|---|---|---|---|
| 지옥 | 180 | 90 | 해당 없음 | 해당 없음 |
| 신 | 201 | 102 | +7 (208) | +10 (112) |
| 악몽 | 211 | 102 | +10 (221) | +15 (117) |

- 계산 방식: "조합 계산기의 '방어력 감소 현재 수치'는 오라형을 합산한 값이며, 발동형은 … 계산기 수치에는 포함하지 않습니다." 이감도 "오라형(유닛 설명 첫 줄의 '이동속도 감소 N%')만 합산"한다.
- 목표 초과: "목표를 얼마나 초과해도 추가 이득이 있는지는 맵 내부 공식에 달려 있어 ORDR이 확인해 드릴 수 없으므로 … '목표 달성 후에는 다른 역할을 우선 점검한다'" (armor-reduction).
- 패치: "2.314 패치에서 라인 몬스터의 방어력이 -20 이하가 되었을 때 데미지가 오히려 줄어들던 버그가 수정"됨 (armor-reduction).
- 이감에는 별도 상한 수치가 없다. 목표만 있다(지옥 90, 신·악몽 102, 나스쥬로 +10/+15).
- 예시: 지옥 방깎은 "로져 60 + 쵸파 50 + 흰수염 45 + 로빈 45 = 200", 이감은 "빅맘 70% + 아오키지 70% = 140" (team-building, slow, hell).
- 방깎 오라 상위: 로져 60, 쵸파(초월) 50, 흰수염(불멸) 45, 로빈(초월) 45, 료우기 시키 44, 에이스(왜곡) 40, 레베카(제한) 38, 35 6종 (armor-reduction).
- 이감 오라 상위: 빅맘 70%, 아오키지(초월) 70%, 카이도 60%, 후지토라(초월) 55%, 타츠마키·로져·스모커(전설) 50% (slow).
- 2.321 패치: 카이도 특강 후 이감이 60%에서 30%로 바뀌었다. 이 점은 상위 표와 함께 확인해야 한다.
- 인게임 확인: 유틸보드(11시 톱니바퀴)의 스펙 확인에서 방깎·이감 오라 총합을 볼 수 있다. "발동형은 모든 유닛이 작동하는 기준으로 표기되기 때문에 실제 적용값과 다를 수 있습니다" (slow, 2.320 패치).

- 초보 실수: "딜러만 모으는 것", "난이도·오로성을 설정하지 않고 판단하는 것"(계산기 기본값은 신), 특성강화 전 툴팁만 보는 것, 패치 후 재확인 누락 (beginner).
- 목표를 넘긴 뒤 낭비: "방깎·이감이 목표를 넘기면 추가 투자는 줄이고 딜러와 제어를 보강하세요."
- 방깎과 이감을 함께 주는 유닛을 우선한다: 로져 60/50%, 사보(초월) 35/35%, 크로커다일(제한) 25/40%, 에이스(왜곡) 40/25%, 조로(초월) 30/30%, 버기(영원) 30/25% (hell/god/nightmare).
- 물리 조합: 방깎이 핵심이다. 마법 조합: "마법방어력 감소 유닛(5종)을 먼저 확보하고, 증폭 유닛을 더한 뒤 딜러" (physical, magic).

### 스턴 (https://ordr.kr/guides/stun)

- 목표값이 없다. 가이드 원문: "스턴에는 그런 목표값이 없어서, 경험으로 판단해야 하는 영역", "방깎·이감 목표와 딜러를 먼저 맞춘 뒤, 보스 라운드나 광폭화 구간에서 부족을 느낄 때 스턴 유닛을 보강".
- 단일 스턴(72종)은 보스·특수몹 제어용이고, 범위 스턴(39종)은 라인 전체 제어용이다.
- "(저항무시)" 스턴은 보스·특수몹 상대로 더 믿을 만하다.
- "스턴이 다른 타이밍에 나오도록 종류를 섞는 편이 안정적"이다(같은 스턴 몰기는 낭비).
- 악몽 워큐리(보스 체력 증가)에서는 보스 제어가 더 중요해진다.

## 3. 코치 적용 제안

1. **라인 판단**(플레이어별): 그 플레이어 자신의 오라 합에 다른 플레이어의 맵 전체 효과를 더한다.
   - 방깎: 우솝초월 +8
   - 이감: 브룩초월 +5%, 냉철함 보상 +7%
   - 공격력: 센고쿠불멸 +11%, 출항 +40%(10초)
   - 같은 효과는 1번만 센다.
2. **스토리 판단**(팀 공통): 스토리 존에 넣은 모든 플레이어 유닛의 적 대상 방깎·이감 오라를 합산한다. 같은 버프 ID는 1번만 센다. 여기에 맵 전체 효과와 개체 디버프(마방·증폭)를 더한다.
   - 비교 기준: 가이드 목표(1인 기준)는 스토리에 그대로 쓰기 어렵다. 파티 플레이에서는 스토리 방어력이 인원수만큼 오른다(배율 미확인).
3. **아군 버프 판단**(스토리 존): 범위 850 이상인 오라는 4명 모두에게 적용한다. 800~825는 이웃 자리에만, 1250(우타)은 전원에게 적용한다.
4. **미확인으로 남길 것:**
   - 2.323에서 우타월드 범위가 바뀌었는지
   - 스토리 인원수 배율
   - 출항·냉철함의 2.323 수치
   - 같은 버프 ID 오라 중첩 규칙(커뮤니티 근거)
