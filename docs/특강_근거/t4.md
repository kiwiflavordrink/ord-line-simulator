# t4 특강 on/off — TR16 아오키지, TR17 아카이누, TR21 보니, TR24 코비, TR25 키드, TR26 키자루, I2 드래곤

- 산출물: `t4.json`(영웅별 current / fix_current / other / unmodeled_other / results), 생성기 `t4work/gen_t4.py`, TR21 주기 모의 `t4work/bonney.py`, 검증 `t4work/val.mjs`.
- 기준 저장소: 커밋 `ebf5f38`(TR17 철저한 정의 stack_target, TR21 age_stack 반영 이후). 저장소는 수정하지 않았다.
- **`other.events` 키는 이벤트 `index` 이름이다.** 엔진 `traitVariant`가 `e.index`로 맞추기 때문이다. 기존 이름(`index`)은 바꾸지 않았다(스택 변형과 함께 쓰므로). 특강 스킬 이름(`<강화>`, 펑크 크래시 등)은 note에 적었다. 검증 스크립트는 모든 키가 실제 이벤트와 맞는지 확인한다.
- 일곱 명 모두 **current = off**다(이벤트 수치·note가 base_lines와 일치하고 "특강 미적용"이라 적혀 있음). 섞인 이벤트가 없어 `fix_current`는 모두 null이다.
- 2.305 특강 구조: 특성포인트(식량) 4를 쓰는 함수가 영웅마다 하나씩 있다. 각 함수는 표시용 능력의 레벨을 올리거나(Aimp) 영웅 유닛을 교체하고, 스킬 트리거가 `GetUnitAbilityLevel(...)==2` / `GetUnitTypeId`로 분기한다.
- 다른 에이전트가 맡은 부분은 건드리지 않았다: TR17 철저한 정의 누적(stack_target)과 TR21 세월관통 적마다 1회(age_stack·requires_stack·stack_add·when_target_stack). 특강 덮어쓰기는 이 필드들을 바꾸지 않으므로 그대로 유지된다.

**특강 on이 off보다 약하게 나온 경우: TR21 위치 모델.**
- 실제 원인: 니카 스킬 마나 소모가 공격당 평균 2.6→3.9로 늘어 니카 창이 7.61→5.20초로 줄어든다. 니카 폼 가동률은 23%에서 17%로 내려간다. 니카 스킬 피해는 커지지만, `requires_stack 40` 조건 때문에 위치 모델에서는 그 몫이 적게 잡힌다.
- 분리 시험(TR21 3기 위치 모델): transform_window만 바꾸면 7.21→2.33, 피해만 바꾸면 7.21→10.20.
- 다만 이 결과는 매우 민감하다. 무특강에서 attack_uptime만 0.9097→0.9025로 바꿔도 7.21→3.50으로 떨어진다(패배 라운드는 같음). 따라서 위치 모델의 on<off는 순위 근거로 약하다. 기본 모델 3기에서는 특강이 낫다(잔존 29→0).
- 2.305 코드처럼 니카 임사체험이 450만이면 특강 쪽이 더 유리해진다.

TR26: 팔지경 타당 피해가 35만→19만으로 줄지만(스택 3), 천총운검과 분신이 더해져 합계는 소폭 오른다.
