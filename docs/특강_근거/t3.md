# t3 특강 on/off 덮어쓰기 — Z1·Z3·Z4·Z7·TR14·TR15

출력: `t3.json` (`heroes.<code>.{current, fix_current, other, unmodeled_other, results}`).
`other.events`의 키는 엔진 `traitVariant`(dist/engine_v3.mjs)가 쓰는 **이벤트 `index` 이름**이다.
생성기: `t3w/gen_t3.py`, 검증: `t3w/val.mjs`. 저장소는 수정하지 않았다.

## 검증 (simulateV2, 신 난이도, 각 영웅 단독)

데이터 복사본에 `trait={current, other}`를 붙이고 `options.traits={code:'on'|'off'}`로 실행했다. 모든 경우에 NaN·예외가 없었다. 값은 결과와 영웅 누적 피해(억)이다.

| 코드 | 기본 1기 off → on | 기본 3기 off → on | 위치 1기 off → on | 위치 3기 off → on |
|---|---|---|---|---|
| Z1 | 61라 패배, 12.12 → 12.70 | 65라 패배 → **클리어 잔존 27**, 230.8 → 270.3 | 61라, 5.81 → 5.89 | 62라, 52.3 → 57.2 |
| Z3 | 61라, 19.80 = 19.80 | 클리어 34 = 34 | 61라, 4.41 → 4.95 | 61라, 13.24 → 14.84 |
| Z4 | 61라, 12.05 → 15.81 | 62라 → 64라, 72.9 → 181.6 | 61라, 5.53 → 6.44 | 61라 → 62라, 24.1 → 41.9 |
| Z7 | 61라, 14.88 → 18.23 | 61라 → 65라, 42.4 → 241.6 | 61라, 3.57 → 4.08 | 61라, 10.26 → 12.14 |
| TR14 | 64라 → 65라, 193.9 → 239.5 | 클리어 0 = 클리어 0, 296.2 → 293.1 | 61라, 7.67 → 8.39 | 61라, 26.5 → 28.8 |
| TR15 | 62라, 87.1 → 98.3 (패배 시점 9 → 14초) | 클리어 2 → 0, 302.4 → 301.0 | 61라, 16.8 → 18.4 | 클리어 9 → 7, 299.2 → 298.2 |

on이 off보다 약하거나 같게 나온 경우:

- **Z3 기본 모델은 완전히 같다.** 기본 폼이 불사조(`permanent_form 0`)이고, 특강으로 바뀌는 봉황인 rate는 인간 폼(`phase 'trans'`) 이벤트에만 있다. 위치 모델에서는 풍압 60% 감속으로 체류가 늘어 피해가 증가했다.
- **TR14·TR15 3기는 피해 합계가 조금 줄었다.** 두 상태 모두 클리어했으므로 이 차이는 몹이 더 빨리 죽어 생긴 초과 피해 감소다. TR15는 잔존 수가 줄었다(2→0, 9→7).
